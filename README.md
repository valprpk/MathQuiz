# Руководство пользователя: Приложение «Математический тест» (Math Quiz)

Добро пожаловать в руководство пользователя приложения «Математический тест». Данная программа предназначена для проверки навыков быстрого устного счета и тренировки базовых арифметических действий.

# 💻 Общее описание программы

«Математический тест»- это интерактивный тренажер, который предлагает пользователю решить четыре случайные математические задачи за строго отведенное время. Программа автоматически генерирует условия, проверяет правильность ответов и помогает развивать концентрацию и скорость мышления.

# Основные возможности:

• Случайная генерация условий: каждый новый тест содержит уникальные числа.                                                                         
• Четыре вида арифметических операций: сложение, вычитание, умножение и деление.                                                            
• Контроль времени: встроенный таймер обратного отсчета держит в тонусе и показывает, сколько секунд осталось до конца сессии.                                   
• Удобный ввод: защита от случайного ввода некорректных символов (букв или знаков) благодаря использованию специальных счетчиков.                          

# 🖥️ Интерфейс программы

Интерфейс приложения максимально прост, лаконичен и состоит из одного рабочего окна, размеры которого зафиксированы для удобства прохождения теста.
1. Панель времени (Time Left): Расположена в правом верхнем углу. Отображает оставшиеся секунды.                               
2. Зона задач: Состоит из 4 строк:
 • Сложение (+)                                           
 • Вычитание (-)                                                
 • Умножение (×)                                           
 • Деление (÷)                                                            
3. Поля ввода ответов: Числовые ячейки со стрелками справа от знака «равно» (=), куда пользователь вводит свои варианты.                     
4. Кнопка управления (Запуск теста): Кнопка внизу экрана для начала тестирования.                                     

# 🕹️ Порядок работы с программой (Как играть)

# 1. Подготовка и старт

• При запуске программы на месте будущих чисел отображаются вопросительные знаки (?).  

<img width="492" height="396" alt="image" src="https://github.com/user-attachments/assets/dabe986d-5d23-4245-9b33-6119d1ed383b" />


• Чтобы начать тестирование, нажмите кнопку «Запуск теста» в нижней части окна.                                       
• Сразу после нажатия запустится таймер обратного отсчета, а вместо знаков вопроса появятся случайные математические примеры. 

<img width="488" height="412" alt="image" src="https://github.com/user-attachments/assets/0f67b1e6-5c93-4c1a-9f5d-a7e95d3a3030" />


# 2. Прохождение теста

• Быстро анализируйте примеры сверху вниз.                                                          
• Вводите числовой ответ в поле соответствующего примера.                                                      
• Вы можете вводить числа как с клавиатуры, так и нажимая на стрелочки «вверх/вниз» на самом поле ввода.                                 
• Секрет быстрого прохождения: Чтобы не тратить время на мышку, используйте клавишу TAB для мгновенного перехода к следующему полю ответа.                      

# 3. Завершение теста

Тест может завершиться двумя путями:                                                          
1. Вы успели решить все правильно: Если все 4 ответа верны до окончания времени, программа сразу останавливает таймер и сообщает вам о победе.

<img width="460" height="508" alt="image" src="https://github.com/user-attachments/assets/17c049af-26ca-452d-ab51-60ef73f077ad" />


2. Время истекло: Если таймер дошел до 0, тест завершается автоматически. Программа покажет, какие ответы были правильными, а где вы допустили ошибку.
